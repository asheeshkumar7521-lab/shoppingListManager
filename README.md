# Shopping List Manager

A simple Shopping List Manager built using HTML, CSS, and JavaScript.

## Features
- Add shopping items
- Delete items
- Empty input validation
- Simple and user-friendly interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository.
2. Open `index.html` in your browser.
3. Enter an item and click the Add button.
4. Click Delete to remove an item.

## Project Purpose
This project was created to practice JavaScript DOM manipulation and event handling.
